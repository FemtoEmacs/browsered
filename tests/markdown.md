# Formatação Markdown

## Títulos e estilos

Texto normal, **texto em negrito**, *texto em itálico* e ***negrito com itálico***. Os acentos devem permanecer corretos: ação, emissão, informação.

### Lista não numerada

- Primeiro item
- Segundo item com **destaque**
  - Item subordinado

### Lista numerada

1. Primeiro passo
2. Segundo passo

> Esta citação deve usar o estilo de citação definido no XML.
